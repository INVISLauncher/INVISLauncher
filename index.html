Sıkça Sorulan Sorular

INVIS Launcher ve indirme süreci hakkında temel sorular.

INVIS Launcher ücretsiz mi?
Evet, INVIS Launcher tamamen ücretsizdir ve içerisinde hiçbir reklam barındırmaz.
İndirme işlemi nasıl gerçekleşiyor?
İndir butonuna tıkladığınızda doğrudan güvenli GitHub Releases sayfasına yönlendirilirsiniz ve en son .exe dosyasını indirebilirsiniz.
Mod ve Shader paketlerini nasıl eklerim?
Launcher içerisindeki 'Keşfet' sekmesinden Modrinth veya CurseForge üzerindeki modları tek tıkla inceleyebilir ve 'Dosyalar' kısmından aktifleştirebilirsiniz.
Farklı tema seçenekleri var mı?
Evet! Ayarlar menüsünden Karanlık, Aydınlık, OLED ve Sistemle Eşle temalarından dilediğinizi seçebilirsiniz.
Java sürümleri nasıl ayarlanır?
Launcher sisteminizdeki Java yollarını (örneğin Java 25) otomatik algılar veya Ayarlar kısmından manuel yol belirlemenize imkan tanır.
